## Custom Keybindings

### Diffview

| Key | Action |
|---|---|
| `<leader>gd` | Open diff view vs main (PR view) |
| `<leader>gD` | Close diff view |

### Octo (PR Review)

| Key | Action |
|---|---|
| `<leader>pr` | List PRs |
| `<leader>po` | Checkout PR |
| `<leader>ps` | Start review |

### Gitsigns

| Key | Action |
|---|---|
| `]c` / `[c` | Next / prev hunk (built-in) |

Inline blame is enabled by default with 300ms delay.
